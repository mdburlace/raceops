## New features
- **Backups and restore:**
    - Platform admins back up the whole server, now or on a schedule, to a server folder, S3-compatible storage, Google Drive, Dropbox or OneDrive.
    - They can restore everything, bring one team back, or move RaceOps to a new server.
    - Each team can back up its own data too.
- **Export your team's data** as CSV, XML or JSON, with or without attached files.
- **Recently deleted:** recover something deleted by mistake, for 90 days unless your platform admin sets otherwise.
- **Training pack:** a quick start, exercises for each role, quick reference cards, short videos and a trainer's guide. Platform admins can create a **practice team** with demo data.
- **Workshop setup sheets:** how each car is set up on the shop floor. Link one to an event, and the track sheets start from it.
- **Engine tunes:**
    - Each engine's tune is kept in versions, with one active.
    - Setup sheets show the pills for tonight's weather, and **Use this jetting** fills them in.
    - Engine builders can share a tune with the owner's team.
- **Engine checks:** the between-race engine service, flagging weak springs, rising leak-down, lash off the tune and plug readings.
- **Repair this device:** for a device that stays **Offline** while the app works everywhere else.

## Improvements
- Attach up to 5 files (20 MB each) to problem reports, requests and ideas.
- The training pack is checked against every release.

## Bug fixes
- A device could get stuck **Offline** because the browser had cached the app's connection to the server. The app no longer allows that, and the badge says **Can’t sync** and points you to **Repair this device**.
- The **Sync** buttons wrap on a phone instead of running off the screen.
- A setup sheet copied from another session no longer picks an engine tune you didn't choose.

## Notes
- Backups need `BACKUP_KEY`. Keep a copy of it away from the server, because restores need it. Cloud destinations need the app registrations described in the README.
