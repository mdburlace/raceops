## New features
- **Release notes** in **Help & guide**: every release, newest first. Each has its summary and date, then its new features, improvements, bug fixes and notes.
- **Version** at the bottom of the sidebar, and **This version** in the release notes.
- After an update, Home shows **RaceOps has been updated** once, with a link to the release.
- **Code repository** setting for platform admins: each release links to its code changes and pull requests on GitHub.

## Improvements
- Problem reports include the app version.

## Notes
- To link the releases to the code, set **Platform admin → Settings → Code repository**, e.g. to *https://github.com/mdburlace/raceops*.
- For whoever changes RaceOps: each release adds a file to `docs/releases`, and the build fails if the newest line in What's new isn't in the newest release's notes. See `CLAUDE.md`.
