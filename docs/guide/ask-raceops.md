**Ask RaceOps** in the menu answers questions about your team's records, for example:

- *What did we run last time the track was slick?*
- *Which shocks are due for service?*
- *How many laps are on the 410 since its freshen?*

Answers link to the setup sheets, events and assets they came from, so you can check them. It only reads what **you** are allowed to see, and it never changes anything.

It needs the AI add-on and a connection. See [AI assistant](/help/ai-assistant).
