Print these and keep them where the work happens: in the trailer, on the workshop wall, in the pit box. [Print the cards](/print/guide?ids=training-cards) — each card prints on its own page.

## Race night

**Before the first session**
- Open tonight's event: **At the Track → Events**. A meeting over more than one day has a tab per day; you're on today's.
- Pick the session beside **+ Add session**, press it, then **Copy this session** (or start from the **Workshop setup**, **Last time out** or a baseline).
- Set pressures, wing and shocks. **Save**. The sheet saves on the phone, even with no signal.
- Pills: fill in the **ADR** in **Weather**, then in **Engine** press **Use this jetting** (from the motor's active tune).

**Between sessions**
- Mechanic: **Between-round checks → New check**. Note anything wrong.
- Record the result, **hot pressures** and **hot stagger** on the session's sheet.
- Record **Track conditions** and how the car behaved (**Driver**, **Crew lead**).
- Next session: pick it, **+ Add session** → **Copy this session** (the one just run is chosen) → make your changes. Changes show *was …* under them.

**After the meeting**
- **Compare sessions** on the event, with **Changes only**.
- **Setup advisor** for anything the car did wrong.
- Check the badge says **Synced** once you're back in signal.

## What goes where

| You want to record… | Where |
|---|---|
| A setup for one session | **At the Track → Events** → the event → the session's sheet |
| A starting setup to reuse | Any sheet → tick **Save as a baseline setup** |
| How the car is set up in the shop | **In the Workshop → Workshop setups**, then link it to the event |
| A quick check between rounds | **At the Track → Between-round checks** |
| A part with a life (shock, bar, wheel, wing, engine…) | **In the Workshop → Assets** |
| A tyre | **Gears & tires → Tires** |
| A weekly or monthly service | **In the Workshop → Car maintenance** → **+ Weekly** (or another level) |
| A job that repeats every so many races or laps | **Car maintenance → Schedules → New schedule** |
| A dyno run or bar test | **In the Workshop → Shock & bar dyno** |
| An engine build | **Engine Builds** → the engine → build sheet |
| A customer's job | **Engine Shop → Jobs → New job** |
| Where you're racing this year | **Team Management → Calendar** |
| Something deleted by mistake | **Recently deleted** (sidebar) |
| A copy of the team's data, putting it back, or an export | **Team Management → Backups & export** |
| A problem with RaceOps, or an idea | **Feedback & roadmap** |

## Offline and sync

| Badge | Meaning |
|---|---|
| **Synced** | Everything's on the server |
| **Syncing** | Sending or fetching now |
| **Waiting to sync** | Saved on this phone. It goes up when there's signal |
| **Offline** | No connection. Keep working as normal |
| **Can’t sync** | This device is stuck. Tap the badge → **Repair this device** |

**Do**
- Install RaceOps on your phone, so it opens without signal.
- Open the app once in signal before you leave for the track, so it has the latest.
- Let it reach **Synced** before you sign out or swap phones.
- Stuck on **Offline** or **Can’t sync** while it works on other phones? **Profile & device → Repair this device**. It keeps your sign-in and anything waiting to sync.

**Don't**
- Clear your browser's data while it says **Waiting to sync**. Those changes are only on the phone.
- Worry about two people editing: the later save wins, and every version is kept in the record's history.

## The workshop week

1. **In the Workshop** hub → **Service due** and **Assets needing attention** (or **Needs attention** on Home).
2. Do the job, then on its schedule press **Done today**.
3. Parts going away for service: set the asset's **Status** to **Out for Service**.
4. **Car maintenance** → **+ Weekly**: tick each item, add measurements, **Save**.
5. Rebuilt shock? **Shock & bar dyno → New shock run**.
6. Engine service: **Engine checks → New engine check**. Readings are compared with the tune and the last check; fix what's flagged and list **Parts needed**.
7. New parts: **Assets → New asset**, with the **car** and **position** set, so setup sheets list them at the right corner.

## An engine shop job

1. **Engine Shop → Jobs → New job**: customer, engine, job type, status.
2. As the work goes: **findings**, **parts** (cost and price), **labour** (hours).
3. **New build sheet** on the job: measurements, clearances, torque.
4. Status through to **Ready for pickup**.
5. **Job sheet / handover pack** → **Print / save as PDF** for the customer.
6. Engine page link (**Customer access**) lets the owner see their engine's history.
7. **Engine tunes → New tune** (or **New version**) for how it should be run. Shared tunes show on the engine page.
